# 使用与故障排查

## 检查进度

“从头匹配”清除上次检查进度，重新从第 1 题读取。“继续匹配”保留已完成的结果，重试第一道未检查完成的题。例如第 20 题超时，前 19 题保留，继续时检查第 20 题。

进度在当前页面内存中，刷新页面后丢失；切换课程、章节、题库、作业，应用匹配设置或采用新的手工答案后需要从头检查。导出的 JSON 是结果报告，不能导入恢复进度。完整检查及试填前不能启动自动提交。

## 三类填充操作

- “填充本题”：匹配并填写当前题，不提交，可用于试填。
- “只填充已匹配题”：重新检查作业，填写匹配成功的可编辑题，再切题回读草稿；不点击提交。部分平台切题不能保留草稿，脚本遇到这种情况停止。
- “逐题填充并提交”：在完整检查、试填且允许使用的前提下，逐题填写、回读、提交并确认新反馈，默认跳过待核对题。

## 手工核对

图片选项、未匹配题或资料含文字差异时，在“预览本题”中选择或填写正确答案，点击“采用以上核对答案”，再从头检查。采用手工答案会清除旧检查计划。题干、图片或选项变更时，原手工结果失效。

人工智能和科研伦理的文字题不按题号匹配。人工智能图片题的章节顺序模式仅在已确认页面与来源顺序一致时使用，参考答案必须能唯一定位选项或与空格数量对应。

## 工程伦理

选择“工程伦理”后自动加载本地参考记录，无需运行时访问微信。选择对应参考章节，并核对当前作业的题号及选项顺序与来源相同，再使用预览、检查和填充。该课程的顺序匹配选项默认开启；顺序不一致或无法核实时应关闭并手工答题。

判断答案“对”选择值为 `true` 的 √ 控件，“错”选择值为 `false` 的 × 控件。脚本不依赖左右位置，也不会把答案字母 A/B 猜成对/错。选择题按来源字母定位当前控件，包括已核对顺序一致的图片选项；无法验证选择题完整题干与选项文字。

各章参考题数如下，第八章包含六条选项答案和两条填空记录：

| 章节 | 记录数 | 章节 | 记录数 |
| --- | ---: | --- | ---: |
| 第一章 | 14 | 第八章 | 8 |
| 第二章 | 14 | 第九章 | 16 |
| 第三章 | 12 | 第十章 | 15 |
| 第四章 | 8 | 第十一章 | 11 |
| 第五章 | 15 | 第十二章 | 15 |
| 第六章 | 14 | 第十三章 | 13 |
| 第七章 | 13 | | |

章节题数不一致、题号无法读取、选项字母缺失或题型不一致时不套用顺序答案；不会跳过来源位置而使后续答案向前错位。可保留“跳过待手工核对题”，脚本处理其余匹配题，待核对题按页面手工完成或在预览中采用核对答案。

第八章两道填空各需三个可识别空格，且完整题干和空格位置一致，分别采用“全体员工 / 工厂主门 / 公众”和“安全发展 / 生命至上 / 安全第一”。这两题按文字匹配，不依赖页面题号；关闭工程伦理顺序匹配后仍可匹配。

## 研究生生涯发展与规划

选择该课程后自动加载第二至十四章共 130 条本地参考记录，每章 10 题，默认章节为第二章。来源没有第一章；该缺席已由用户确认，不补造或挪用第二章答案。

用户已核对这门课的题号及选项顺序与资料一致，因此默认启用“生涯规划按章节、题号和选项字母匹配”。其他使用者需自行核对；顺序不一致时关闭该选项并在预览中手工选择正确答案。匹配会校验章节题数、页面题号、题型和选项控件，无法验证完整题干及选项文字。对/错按 true / false 控件选择 √ / ×，ABC 等多选答案逐一映射到当前字母。

第二章第 9、10 题按用户核对分别采用 **D、B**，不将原表第 9 题单元格的 `DB` 当成一道多选答案。两题的预览及匹配报告保留原值和修正说明，其他题目位置不变。

仍可从头匹配、继续匹配、跳过待手工核对题，以及试填核对后的逐题操作。切换课程或参考章节、关闭顺序匹配、重读题库或采用手工答案后，需要重新检查。此资料没有填空题题干，当前页面如果出现填空题应手工处理。

## 信息素养：学术研究的必修课

选择该课程自动加载第 1～12 周共 109 条本地参考记录，不需要再下载图片或在浏览器中运行 OCR。默认“自动按题干匹配全部章节”，也可选择对应周次来缩小范围。

小节题号各自从 1 开始，不能按周次题号直接套答案。脚本匹配完整题干、题型及整组选项文字，然后将正确选项文字映射到页面当前字母；支持题目换序、多达七个选项，以及 true / false 的判断控件。检索运算符、引号、英文词间空格和文件名大小写保留，不把 `+` / `*` 或 `download_***` / `Download_***` 当成同一选项。

点击“预览本题”后可展开参考记录 ID，打开来源截图核对。报告中的 `sourceRecordId`、`sourceImages` 和 `referenceAnswerRaw` 分别记录唯一来源编号、截图链接及原答案字段。疑似错字或文字差异、图片题及没有资料的题需手工核对；仍可跳过这些题，处理其余匹配成功的题。

期末部分按用户要求不收录；第九周的 5.4 小节在来源页面没有截图，未补造。完整范围和资料核对说明见 [信息素养资料说明](information-literacy.md)。更新后刷新作业页，重新选择课程、检查匹配并试填核对一题。

## 常见停止原因

| 提示 | 处理方式 |
| --- | --- |
| 没找到答案控件、题型未适配 | 确认当前页面已加载；尝试导出诊断或手工处理 |
| 字体读取失败 | 检查静态资源请求及网络，恢复后重试；不要用乱码推测答案 |
| 切题超时 | 等页面加载完成，在相同页面点击“继续匹配” |
| 工程伦理章节题数或题型不一致 | 核对当前课程、章节及来源；不擅自补题或调整答案位置，必要时手工处理 |
| 生涯规划章节题数或题型不一致 | 确认所选章节为第二至十四章、作业共 10 题及顺序一致，必要时手工处理 |
| 信息素养题干、题型或完整选项不一致 | 核对周次及来源截图，注意检索符号、大小写和来源错字；不能按重复题号猜答案，可跳过或采用手工核对答案 |
| 未提交草稿弹窗 | 用户核对并手动处理网页弹窗，脚本在检查时不代为提交 |
| 页面已有不同答案 | 默认保留，核对后再决定是否启用覆盖 |
| 提交失败或确认超时 | 查看真实页面结果并自行处理；脚本不会重复点击提交 |

提交反馈不等于成绩或答案已正确。所有真实操作均需符合学校、课程和平台规则。
