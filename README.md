# RainClass Autofill · 个人自用学习脚本

[![Tests](https://github.com/hrx0908/rainclass-autofill/actions/workflows/test.yml/badge.svg)](https://github.com/hrx0908/rainclass-autofill/actions/workflows/test.yml)
[![Version](https://img.shields.io/badge/version-0.1.21-green.svg)](CHANGELOG.md)

**本仓库用于记录本人自用脚本的学习、维护和技术实验，不作为面向公众的答题工具或服务，不提供对外使用支持、他人课程适配或代做代答服务。**

脚本运行于 Tampermonkey，记录题干匹配、预览核对、进度续查及页面控件操作的实现。本人与雨课堂、学堂在线、学校及课程提供方无隶属、合作或授权关系。

本人使用前仍须确认学校、教师和平台允许相关辅助操作，遵守学校纪律、课程及考试要求、学术诚信规范、平台条款和适用法律法规。个人自用的用途说明不能代替这些要求，也不表示获得了相关授权或可以免责。

**0.1.21 暂时移除“信息素养：学术研究的必修课”。** 当前脚本不包含该课程的入口、题库和匹配模块，旧版本的相关记录仅保留在版本历史中。

本人维护的功能包括填空、单选、多选、判断及具有完整步骤说明的排序选择题；面板支持拖动、预览、手工核对、从头匹配和继续匹配。批量操作前需完整检查及试填回读，默认跳过待核对题并保留已有不同答案；提交失败或超时停止，不因超时重复提交。

工程伦理和生涯规划的资料大多只有答案字母及“对/错”，题数一致不能证明题目或选项顺序一致。顺序无法核实时须关闭相应模式，手工处理。生涯规划第二章第 9、10 题依据本人核对分别采用 D、B，来源原值和修正说明保留。字体及页面适配限于本人已核对的范围。

## 本人维护记录

当前版本为 0.1.21，脚本源文件是 `rainclass-autofill.user.js`，更新元数据是 `rainclass-autofill.meta.js`。沿用原 namespace，避免在本人浏览器中同时启用多份脚本。升级后刷新页面，重新选择课程、检查匹配并试填核对。

检查进度仅保存在当前页面会话内，刷新页面、更换作业、课程、章节、题库或设置后需要从头检查。遇到未提交草稿弹窗，由本人手工核对处理；“停止”不能撤回已经发出的提交请求。

详细操作及排查笔记见 [本人使用笔记](docs/usage.md)，版本变更见 [CHANGELOG.md](CHANGELOG.md)。这些文件用于本人记录维护过程，不构成向他人提供服务或保证适配的承诺。

## 数据与维护检查

脚本在匹配的雨课堂页面读取题干和选项，按本人主动指令操作答案控件。网络参考页及字体使用匿名请求；没有独立服务器，不向维护者上传题目、答案、成绩或登录资料，也不读取 Cookie 或登录令牌。面板位置保存在浏览器本地，进度和手工核对记录保存在当前页面内存中。

诊断和匹配报告可能包含作业 URL、课程及题目内容。本人不将账号、姓名、学号、成绩、Cookie、令牌、完整登录页面或未经许可的原文、字体发布到仓库。

本地检查使用 Node.js 22：

```sh
npm ci
npm run sync-meta
npm run check
npm test
```
