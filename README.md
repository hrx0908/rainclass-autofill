# RainClass Autofill · 雨课堂学习辅助脚本

[![Tests](https://github.com/hrx0908/rainclass-autofill/actions/workflows/test.yml/badge.svg)](https://github.com/hrx0908/rainclass-autofill/actions/workflows/test.yml)

[![Version](https://img.shields.io/badge/version-0.1.20-green.svg)](CHANGELOG.md)

运行在 Tampermonkey 中的雨课堂学习辅助脚本。通过题干、空格位置和选项文字匹配参考资料，提供答案预览、手工核对、检查进度续查，以及用户主动启动的填充和逐题操作。

**本项目仅供学习、复习和脚本技术研究。参考答案来自公开网络资料及用户提供的整理内容，不代表开发者或平台的标准答案，也不保证正确。使用前须确认学校、教师和平台允许相关操作。**

本项目是个人开源项目，与雨课堂、学堂在线、学校或课程提供方无隶属、合作或授权关系。

## 功能

- 支持填空、单选、多选、判断，以及列出完整步骤说明的排序选择题。
- 人工智能、科研伦理的文字题按题干和完整选项匹配，支持题目及选项换序；冲突或缺失的答案留待手工核对。
- 信息素养按完整题干、题型和整组选项文字匹配，保留检索运算符、引号、词间空格和大小写，支持重复题号及选项换序。
- 工程伦理、生涯规划参考资料主要提供答案字母和“对/错”，按已核对一致的章节、题号和选项顺序匹配，并检查章节题数及页面题型。“对”对应 √，“错”对应 ×，通过控件的 true / false 值定位。
- 预览参考答案，采用手工核对结果，再填充当前题并回读页面状态。
- 检查提供“从头匹配”和“继续匹配”。超时或停止后保留当前页面内已完成的检查结果。
- 可跳过待核对题，仅处理匹配成功题；默认保留页面上已有的不同答案。
- 批量提交前必须完成检查并试填一题；按题独立处理，收到页面反馈后继续，提交失败或超时停止。
- 操作之间有节奏停顿，并等待页面加载；不承诺规避平台检测，也不用于绕过访问限制。
- 面板可拖动、收起和恢复位置，可导出匹配报告用于排查。

当前包含“人工智能安全与伦理”的参考页解析、“科研伦理与学术规范”第一至六章的 107 条参考记录、“工程伦理”第一至十三章的 168 条参考记录、“研究生生涯发展与规划”第二至十四章的 130 条参考记录，以及“信息素养：学术研究的必修课”第 1～12 周的 109 条参考记录。生涯规划第一章不在来源资料中，不补造题目；信息素养不含期末题。题库与字体适配具有课程和页面范围限制，不适用于所有雨课堂课程。

## 安装

1. 在 Edge 或其他兼容浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击 **[安装最新版脚本](https://raw.githubusercontent.com/hrx0908/rainclass-autofill/main/rainclass-autofill.user.js)**，在扩展中确认安装。若链接只显示文本，可复制全部内容到油猴的“创建新脚本”编辑器并保存。
3. 打开允许使用辅助工具的雨课堂作业或练习页，刷新后出现“雨课堂填充”面板。

支持的页面路径为 `https://www.yuketang.cn/ai-workspace/lms-graph/*/exercise/*` 及无 `www` 的同类路径。旧用户可直接更新；沿用原脚本 namespace，只启用一份脚本。

已设置版本检查与下载地址，元数据含义见 [Tampermonkey 官方文档](https://www.tampermonkey.net/documentation.php?q=update_url)。更新是否生效仍取决于扩展的更新设置及网络可用性。

## 使用流程

1. 选择课程和参考章节。人工智能课程点击“读取参考题库”；其他四门课程选择后加载内置题库。工程伦理、生涯规划必须选择与当前作业对应的章节，并确认题号和选项顺序与来源一致。信息素养默认按题干匹配全部周次，也可指定某周。
2. 点击“从头匹配”。检查仅读取题目，不填写或提交。中途超时、停止后，页面恢复即可点击“继续匹配”。
3. 检查完成后，选一道匹配成功的题，点击“预览本题”，自行核对，再点击“填充本题”，确认页面内容或勾选状态正确。
4. 在已获得使用许可的情况下，自行选择只填充已匹配题，或逐题填充并提交。结束后核对页面结果，手工完成被跳过的题。

人工智能课程的图片题按章节题号匹配仅适用于已自行确认题目顺序一致的章节，且答案仍须能唯一映射到当前选项。人工智能、科研伦理的图片选项需要手工核对。

工程伦理的顺序匹配仅用于该课程。默认启用“工程伦理按章节、题号和选项字母匹配”，适用于用户已确认顺序一致的页面；其他使用者须自行核对。该资料没有完整选择题题干，因此无法判断题目或选项是否换序，题数相同也不能证明顺序一致。顺序不一致时请关闭该选项并手工核对。第八章两道三空题按完整题干和空格位置匹配，分别为“全体员工 / 工厂主门 / 公众”和“安全发展 / 生命至上 / 安全第一”，不依赖页面题号。各章参考题数及停止原因见 [使用说明](docs/usage.md#工程伦理)。

生涯规划同样按用户已核对的章节、题号及选项顺序匹配，默认启用该课程单独的顺序匹配选项；每章 10 题。第二章原表把 `DB` 放在第 9 题单元格并将第 10 题留空；根据用户核对，分别采用第 9 题 `D`、第 10 题 `B`。预览与报告注明这两处修正，其他单元格按原值收录。来源未提供完整题干，顺序不一致时应关闭顺序匹配并手工处理。详见 [生涯规划使用说明](docs/usage.md#研究生生涯发展与规划)。

信息素养使用用户提供并核对的截图文字转录：第 1～12 周共 109 条，含 63 道单选、44 道多选和 2 道判断题；期末部分已排除。各小节题号会重复，因此不按题号匹配。检索式中的 `+`、`*`、减号、引号，以及 `download_***` / `Download_***` 的大小写分别保留；题干或选项不同则留待手工核对，不自动改写来源错字。预览可打开来源截图，报告带唯一记录 ID。详见 [信息素养说明](docs/information-literacy.md)。

**继续匹配的进度保存在当前页面会话内。刷新页面、更换作业、课程、章节、题库或匹配设置后，需要从头检查。** 扫描遇到未提交草稿弹窗时停止，用户手动处理后再继续。提交已经发出时，“停止”不能撤回请求；脚本不会因超时重复提交。

## 数据与权限

安装的浏览器扩展及脚本会在匹配的雨课堂页面读取题干和选项，并按用户指令操作答案控件。人工智能参考页和字体请求使用匿名请求；脚本没有独立服务器，不向开发者上传题目、答案、成绩或登录资料，也不读取 Cookie 或登录令牌。

面板位置保存于浏览器本地存储；检查结果和手工核对答案在当前页面内存中保存。导出的诊断或匹配报告可能含作业 URL、课程信息和题目内容，分享前请自行检查并删除个人及敏感信息。扩展权限及所在平台本身的数据处理行为不由本脚本控制。
